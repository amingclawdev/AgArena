# AgArena

A hackathon project exploring weather forecasts, farmer notifications, and maps that show the relevant farm area.

## Project direction

- Help farmers understand upcoming weather for their location.
- Notify farmers about weather conditions relevant to their work.
- Show the farm or affected area on a map.

## Status

Repository initialized for team planning. Product requirements, architecture, data sources, and implementation will be decided after the team discussion. There is no application to run yet.
